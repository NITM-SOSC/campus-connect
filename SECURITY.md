# Security Policy

## Project status

Campus Connect is an early-stage project. There is currently no implemented application or published supported software release. This policy will be updated as the project develops.

## Reporting a vulnerability

**Please do not report suspected vulnerabilities in public issues, discussions, or pull requests.** Do not include exploit details or sensitive information in public channels.

If GitHub's private vulnerability reporting feature is enabled for this repository, use it to contact the maintainers privately. If it is unavailable, contact a repository maintainer privately through GitHub and ask for a secure reporting route. Do not send sensitive details until a private channel is confirmed. No response-time commitment is currently established.

Include only information necessary to understand and reproduce the concern, and avoid accessing, changing, or retaining data that is not yours. Please allow maintainers an opportunity to assess and address a report before publicly disclosing details.

## Scope and supported versions

There are no application releases or supported versions at this time. The policy's scope will be clarified when software is implemented and released. Third-party services and systems are outside the scope of this repository's security policy.
